# SecureFlat CMS
**SecureFlat CMS** — это сверхлегкая, безопасная и быстрая Flat-File (без базы данных) система управления контентом, упакованная в **один единственный файл** `index.php`. 

Являясь современной и безопасной альтернативой таким решениям, как Textolite, она предлагает встроенный WYSIWYG-редактор, файловый менеджер и нативную поддержку современных CSS-фреймворков (Tailwind CSS, Bootstrap и др.) при максимальном уровне защиты.

---

## ✨ Особенности

- 🚀 **Архитектура одного файла**: Весь движок находится в `index.php`. Данные хранятся в защищенной папке `sf_data/`.
- 🗄️ **Без базы данных**: Использует атомарную запись JSON-файлов с блокировкой (`LOCK_EX`).
- 🎨 **Поддержка CSS-фреймворков**: Легкое подключение внешних CDN (Tailwind, Bootstrap) через панель настроек с возможностью полного отключения встроенных стилей.
- 🛡️ **Усиленная безопасность**:
  - Хеширование паролей: **Argon2id** (с автоматическим откатом к **Bcrypt**, если хостинг не поддерживает Argon2).
  - Защита от **XSS**: Многоступенчатая очистка HTML на основе белых списков тегов и атрибутов.
  - Защита от **CSRF**: Уникальные токены для каждого POST-запроса.
  - Защита от **Path Traversal**: Строгая валидация путей через `realpath`.
  - **Rate Limiting**: Защита от брутфорса при входе (блокировка по IP).
  - **Secure Sessions**: Куки с флагами `HttpOnly`, `SameSite=Strict`, `Secure`.
  - **Динамический CSP**: Content-Security-Policy автоматически адаптируется под подключенные внешние CSS-ресурсы.
- 📝 **Встроенный WYSIWYG-редактор**: Поддержка drag-and-drop и вставки изображений из буфера обмена прямо в текст.
- 📁 **Файловый менеджер**: Загрузка файлов с строгой проверкой MIME-типов (защита от загрузки вредоносных скриптов).
- 📱 **Адаптивный дизайн**: Панель управления и публичная часть корректно отображаются на мобильных устройствах.

---

## ⚙️ Требования

- PHP **8.1** или выше.
- Расширение PHP: `fileinfo` (для проверки MIME-типов загружаемых файлов).
- Права на запись в директорию, где находится `index.php` (для автоматического создания папки `sf_data`).

## 📦 Установка

Установка занимает менее 1 минуты и не требует консоли или Composer:

1. Скачайте файл index.php.
2. Загрузите его в **пустую папку** на вашем веб-сервере (через FTP, SFTP или файловый менеджер хостинга).
3. Откройте эту папку в браузере (например, `https://yourdomain.com/`).
4. Следуйте инструкциям на экране: придумайте надежный пароль администратора (минимум 8 символов).
5. Готово! Система автоматически создаст защищенную директорию `sf_data/` и сгенерирует главную страницу.

> ⚠️ **Важно**: Убедитесь, что веб-сервер имеет права на запись в папку, куда вы загрузили `index.php` (рекомендуемые права: `755` или `777` для процесса установки, после чего права можно вернуть к `755`).

## 🎨 Использование CSS-фреймворков

SecureFlat CMS разработана с учетом современной веб-разработки. Чтобы использовать свой дизайн:

1. Войдите в админ-панель (`?admin`).
2. Перейдите в раздел **⚙ Настройки**.
3. В поле **"URL пользовательского CSS"** вставьте ссылку на CDN, например:
   - Tailwind CSS: `https://cdn.jsdelivr.net/npm/tailwindcss@2.2.19/dist/tailwind.min.css`
   - Bootstrap: `https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css`
4. (Опционально) Установите галочку **"Отключить встроенные стили CMS"**, чтобы использовать только классы вашего фреймворка.
5. Нажмите "Сохранить". CMS автоматически обновит заголовок `Content-Security-Policy`, чтобы разрешить загрузку стилей с указанного домена.

## 🔒 Архитектура безопасности

| Уязвимость | Мера защиты в SecureFlat CMS |
| :--- | :--- |
| **XSS (Межсайтовый скриптинг)** | Строгий whitelist тегов и атрибутов. Удаление `on*` событий и `javascript:` URI до этапа рендеринга. |
| **CSRF (Подделка межсайтовых запросов)** | Обязательная проверка криптографически стойкого токена в каждом POST-запросе. |
| **Path Traversal** | Функция `sf_secure_path` использует `realpath` и запрещает любые последовательности `../` на строковом уровне. |
| **Брутфорс паролей** | Rate Limiting: максимум 5 попыток входа за 15 минут с одного IP-адреса. |
| **Угон сессии** | Сессия администратора жестко привязана к IP-адресу (`$_SESSION['sf_ip']`). |
| **Повреждение данных** | Атомарная запись: данные сначала сохраняются во временный файл с `LOCK_EX`, а затем переименовываются. |
| **Загрузка вредоносных файлов** | Двойная проверка: через `finfo` (MIME-type) и эвристический анализ содержимого (для SVG). |

## 🛠️ Решение частых проблем (Troubleshooting)

### Ошибка HTTP 500 при установке
Если после ввода пароля вы видите белую страницу или ошибку 500:
1. **Проверьте права доступа**: Убедитесь, что папка, в которой лежит `index.php`, доступна для записи веб-сервером (права `755` или `777`).
2. **Версия PHP**: Убедитесь, что на хостинге включена версия PHP 8.1 или выше.
3. **Очистка**: Если папка `sf_data` была создана с ошибочными правами, удалите её вручную через FTP и обновите страницу. Скрипт автоматически создаст её заново с корректными правами.
4. **Алгоритм хеширования**: Если ваш хостинг не поддерживает `Argon2id`, скрипт **автоматически** и безопасно переключится на `Bcrypt`. Дополнительных действий не требуется.

## 📂 Структура данных

После установки в папке со скриптом появится директория `sf_data/`:
```text
your-website/
├── index.php           # Единственный файл движка
└── sf_data/            # Защищенная директория (доступ запрещен через .htaccess)
    ├── .htaccess       # Запрет прямого доступа извне
    ├── index.html      # Fallback для защиты от листинга директорий
    ├── config.json     # Настройки сайта и меню
    ├── users.json      # Хеш пароля администратора
    ├── log.json        # Журнал действий (последние 500 записей)
    ├── rate_limit.json # Данные для защиты от брутфорса
    ├── pages/          # JSON-файлы с содержимым страниц
    └── uploads/        # Загруженные изображения и документы
